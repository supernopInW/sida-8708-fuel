# ฐานข้อมูล 50 หมู่บ้าน 5 ตำบล อำเภอสีดา จังหวัดนครราชสีมา (30430)

ใช้เป็นข้อมูลอ้างอิงสำหรับระบบแผนการเดินทาง T&V, การค้นหาพิกัดบน [DOH TO TRAVEL](https://dohgis.doh.go.th/dohtotravel/), และการแยกแยะชื่อหมู่บ้านซ้ำใน `doh_logic.js`

## จุดเริ่มต้นและจุดกลับ (Origin / Return)
- **ชื่อ:** สำนักงานเกษตรอำเภอสีดา
- **คำค้น DOH:** `สำนักงานเกษตรอำเภอสีดา`
- **ที่อยู่เต็ม:** `กรมส่งเสริมการเกษตร สำนักงานเกษตรอำเภอสีดา หมู่ 1 ต.สีดา อ.สีดา จ.นครราชสีมา 30430`
- **ขอบเขตพิกัด อ.สีดา (Bounding Box):** `lat ∈ [15.38, 15.74]`, `lon ∈ [102.40, 102.78]`

## จุดระวังชื่อหมู่บ้านซ้ำ / คล้ายกัน
1. **`บ้านโนนเมือง`** มี 2 แห่งใน อ.สีดา:
   - ต.สีดา หมู่ที่ 3 (`สีดา-m3`) → คำค้น `บ้านโนนเมือง สีดา สีดา`
   - ต.สามเมือง หมู่ที่ 2 (`สามเมือง-m2`) → คำค้น `บ้านโนนเมือง สามเมือง สีดา`
2. **`บ้านหนองตาด`** (ม.2 ต.หนองตาดใหญ่) กับ **`บ้านหนองตาดใหญ่`** (ม.1 ต.หนองตาดใหญ่):
   - ต้องให้คะแนน Exact Match บนชื่อหมู่บ้าน + ตรวจ `หมู่ที่ 2` / `หมู่ที่ 1` เสมอ เพื่อไม่ให้เลือกผิดหมู่
