🌐 **เปิดใช้งานผ่านเว็บ (GitHub Pages):** https://supernopinw.github.io/sida-8708-fuel/

ระบบครบวงจรสำหรับจัดทำใบเบิกค่าใช้จ่ายในการเดินทางไปราชการ (**แบบ 8708**, **บก.111**, **หน้างบค่าน้ำมัน**, **ภาคผนวกแผนที่ DOH**) โดยอ้างอิงแผนการเดินทาง T&V (`.docx`) และดึงระยะทาง + แคปรูปแผนที่จาก [DOH TO TRAVEL](https://dohgis.doh.go.th/dohtotravel/) อัตโนมัติ พร้อมปัดเศษระยะทางลงเป็นจำนวนเต็มกิโลเมตรเสมอ (`Math.floor`)

## เริ่มใช้งานด่วน (เลือกได้ 2 รูปแบบ)

### รูปแบบที่ 1: ใช้งานบนคอมพิวเตอร์ (เร็วที่สุด ไม่ต้องต่อ Google)
1. แตกโฟลเดอร์ `แบบ8708_พร้อมใช้` เก็บไว้ในเครื่อง (เช่น `D:\แบบ8708_พร้อมใช้`)
2. ดับเบิลคลิก **`1_เปิดระบบ8708.bat`** → หน้าเว็บแบบ 8708 จะเปิดขึ้นมาอัตโนมัติ
3. *(ทำครั้งเดียว 20 วิ)* เปิด `chrome://extensions` (หรือ `edge://extensions`) → เปิด **Developer mode** → กด **Load unpacked** → เลือกโฟลเดอร์ `sida-doh-auto-bot`
4. กลับหน้าเว็บ 8708 กด **`F5`** → ขึ้นป้ายสีเขียว **`🟢 เชื่อมต่อ DOH Auto-Bot พร้อมดึงอัตโนมัติ`** → นำเข้าไฟล์ `.docx` แล้วกด **`🤖 ค้นหา + แคปรูปจาก DOH อัตโนมัติ`**

### รูปแบบที่ 2: ใช้งานออนไลน์ผ่าน Google Apps Script + Google Sheets/Drive
1. เปิด Google Sheets ใหม่ → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. คัดลอกไฟล์ในโฟลเดอร์ `apps-script/` ไปวาง 4 ไฟล์หลัก (`Code.gs`, `Index`, `DohJs`, `AppJs`) + `appsscript.json`
3. กด **Deploy → New deployment → Web app** → เปิดลิงก์เว็บแอปบน Chrome/Edge ที่ติดตั้งบอทไว้แล้ว
4. บอทจะเชื่อมต่อให้อัตโนมัติ พร้อมแถบ **`☁️ บันทึกลง Drive/Sheets`** และ **`📂 โหลดจาก Sheets`** สำหรับเก็บงานและรูปแผนที่ขึ้นคลาวด์

## กฎการคำนวณสำคัญในระบบ
- **ลำดับเส้นทางทุกวัน:** `สำนักงานเกษตรอำเภอสีดา → หมู่บ้านตามลำดับในแผน → สำนักงานเกษตรอำเภอสีดา`
- **เงื่อนไข DOH TO TRAVEL:** `ถนนหลัก (สั้นและตรง)` (`mode=c`, `type=25`)
- **การปัดระยะทางลง:** ปัดลงเป็นจำนวนเต็มกิโลเมตรเสมอ (`42.66 → 42 กม.`, `35.99 → 35 กม.`)
- **ยอดค่าพาหนะ:** `กิโลเมตร(ปัดลง) × อัตราบาท/กม.` (ค่าเริ่มต้น `4 บาท/กม.` แก้ครั้งเดียวมีผลทั้งเดือน)
- **ไม่ล็อกปุ่ม:** ระบบจะแสดงแถบสถานะ `หลักฐาน DOH: X / N วัน` และแจ้งเตือนวันขาดรูปโดยไม่ขัดขวางการพิมพ์หรือส่งออกเอกสาร

## การแก้ปัญหาที่พบบ่อย (Troubleshooting)
| อาการ | วิธีแก้ไข |
|---|---|
| ป้ายบอทยังขึ้น *"ยังไม่พบส่วนเสริม"* | ตรวจว่าเปิด **Developer mode** ค้างไว้ใน `chrome://extensions` และกด **`F5`** รีเฟรชหน้าเว็บ 8708 (หากเปิดไฟล์ `.html` ตรงๆ โดยไม่ผ่าน `.bat` ต้องเปิด **Allow access to file URLs** ด้วย) |
| เว็บ DOH ขึ้นหน้ายืนยันตัวตน (CAPTCHA) | บอทจะหยุดและสลับไปที่แท็บ DOH ให้คุณยืนยันตัวตนด้วยตนเอง เสร็จแล้วกลับมากดดึงต่อเฉพาะวันที่ยังขาดได้ทันที |
| อยากล้างพิกัดหมู่บ้านที่จำไว้ | คลิกไอคอนส่วนเสริม **DOH Auto-Bot** มุมขวาบนของเบราว์เซอร์ → กด **ล้างแคชพิกัด** |
