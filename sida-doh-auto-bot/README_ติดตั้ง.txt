  คู่มือติดตั้งส่วนเสริม DOH Auto-Bot (ติดตั้งครั้งเดียว ใช้เวลา 30 วินาที)
  สำหรับระบบเบิกค่าน้ำมัน แบบ 8708 + บก.111 สำนักงานเกษตรอำเภอสีดา
=====================================================================

รองรับทั้ง Google Chrome และ Microsoft Edge (Windows / Mac / Linux)

ขั้นตอนติดตั้ง (ทำครั้งเดียว):
1. แตกไฟล์ ZIP นี้เก็บไว้ในโฟลเดอร์ถาวร (เช่น D:\sida-doh-auto-bot) ห้ามลบโฟลเดอร์ทิ้งหลังติดตั้ง
2. เปิดเบราว์เซอร์ Chrome หรือ Edge แล้วพิมพ์ในช่อง Address Bar:
   - สำหรับ Google Chrome พิมพ์: chrome://extensions
   - สำหรับ Microsoft Edge พิมพ์: edge://extensions
3. เปิดสวิตช์ "โหมดนักพัฒนาซอฟต์แวร์" (Developer mode) มุมขวาบน (หรือแถบซ้ายใน Edge)
4. กดปุ่ม "โหลดส่วนขยายที่ยังไม่ได้แพ็กเกจ" (Load unpacked)
   แล้วเลือกโฟลเดอร์ sida-doh-auto-bot ที่แตกไฟล์ไว้
5. [สำคัญถ้าเปิดจากไฟล์ .html ออฟไลน์ในเครื่อง]:
   กดปุ่ม "รายละเอียด" (Details) ของส่วนเสริม "DOH Auto-Bot"
   แล้วเปิดสวิตช์ "อนุญาตให้เข้าถึง URL ของไฟล์" (Allow access to file URLs)

วิธีใช้งาน:
- รีเฟรชหน้าเว็บแบบ 8708 (กด F5)
- แถบด้านบนขั้นตอนที่ 5 จะขึ้นสีเขียว "🟢 เชื่อมต่อ DOH Auto-Bot พร้อมทำงานอัตโนมัติ"
- นำเข้าไฟล์แผน T&V (.docx) แล้วกดปุ่ม:
  "🤖 ดึงระยะทาง + แคปรูปจาก DOH อัตโนมัติทั้งเดือน"
  ระบบจะเปิดเว็บ DOH TO TRAVEL ค้นหาระยะทางทุกวัน ปัดลงเป็น กม. เต็ม
  แคปภาพแผนที่พร้อมลายน้ำกรมทางหลวง และกรอกเข้าตาราง 8708 ให้อัตโนมัติทันที!
